# SHORTETH｜獨立 ETH 空頭策略控制台

從 [eth1003](https://github.com/chenyu951216-afk/eth1003) 的 `c086d55719abdde256077017883aaf2950ceec67` 複製網站、Bitget 對接、加密保存和帳本，另建此專案。沒有修改或重啟原多頭程式。Bitget API adapter `shorteth/exchange/bitget.py` 與該版逐位元相同；進出場方向由策略與執行層提供。

## 網站功能

- 全中文、手機／電腦分頁：總覽、策略訊號、連線、訂單持倉、交易開關、損益、歷史報告、運行紀錄。
- Bitget Classic／UTA、Demo／Live，簽名、時間校正、150 倍／全倉／單向設定與回讀沿用原對接。
- 管理密碼雜湊保存，API 設定由密碼衍生金鑰加密保存；獨立資料目錄、Cookie、帳本與 clientOid 前綴，不複製多頭帳號、密碼或委託紀錄。
- 登入連線後每30秒掃描；下單許可和自動下單均開啟才執行。停止／重啟後預設不送單，重啟須登入解鎖並重新啟用。關閉瀏覽器不停止已開啟的背景服務。
- 最小空單測試：先預覽，網站輸入對應確認文字後才賣出開空，回讀成交，再買入只減倉平空。測試可能產生費用；狀態不明不重送。
- 原有限價修改、取消、人工部分／全部平倉、額外交易所 TP／SL、明確接管既有空單功能保留。接管要求可核對建立時間，避免168小時期限重置。
- 實際損益與交易所紀錄持久保存、去重、可下載。交易所歷史可能包含手動／測試交易，不能冒稱純策略績效；缺少 netProfit 不當成零，外部入金不列交易獲利。

## 固定策略契約

1. 訊號使用 Binance ETHUSDT 永續、從2020開始連續的已完成1小時收盤；EMA720採第一根種子，動能是 `close / 1440小時前close - 1`，暖機後從索引1441開始容許進場。
2. 原空頭狀態在60天動能 `< -5%` 且收盤 `< EMA720` 啟動。持續到動能 `>= 0` 或收盤 `>= EMA720` 才解除；不是一回到−5%以上就出場。
3. 進場另要求收盤 `< EMA720 × 0.99875`。0.125%緩衝只限制進場，不會自行觸發出場。最多一筆ETH空單，不做多、不加倉。
4. 新單名目 `min(當時帳戶權益 × 0.0195 × 150, 200000 U)`，先向下取整至0.01 ETH，再檢查交易所規格。150倍不會重複相乘。100U時目標292.50U，實際取整略小。
5. 每筆出場優先順序：原空頭狀態解除 → 前一根完整小時收盤達實際成交均價×1.06 → 持倉168個小時。以市價買入 `reduceOnly` 平實際剩餘空單。
6. **6%是小時收盤確認，不是交易所盤中觸價停損。**無固定止盈；自動策略不額外掛原生TP／SL。人工加掛會改變已回測規則。70%是歷史尺寸篩選條件，不是額外70%實盤停損。
7. 因停損／到期出場後，等原始空頭狀態解除才容許再進。出場要求及重進鎖保存於SQLite，即使重啟、部分成交、取消未成交餘量後價格恢復，都繼續完成該次退出。
8. 持倉期間入金不補倉；下一次新開倉才用最新權益。程式不會替使用者轉帳。月入300U只是歷史假設，實際金額不固定。

只處理當下可觀察的決策，不補下停機期間的歷史單。開機時原狀態已成立且緩衝達標可按當下價格進場。網站顯示觀察延遲和漏掃小時。資料缺口、未明委託、未明持倉阻擋操作，不能聲稱停機斷線都絕不漏單。

## 與多頭同時運行

**請用獨立 Bitget 子帳戶／獨立資金。**兩套沿用單向模式，不能在同一帳戶同一ETH合約安全地當成兩份獨立多空倉位。新程式有未知ETH持倉／委託時擋單；其他商品持倉亦會阻擋新開倉，以免將共用全倉資金冒充獨立回測。僅換API key但仍指向同一帳戶並不構成隔離。

## 本機與 Zeabur

```powershell
py -3.14 -m pip install -e ".[test,backtest]"
py -3.14 -m shorteth.cli web
```

開啟 `http://127.0.0.1:8766`，建立自己的管理密碼，再從網站填入API。預設資料在 `~/.shorteth`，可用 `SHORTETH_DATA_DIR` 指定。手機同網路可用 `py -3.14 -m shorteth.cli web --lan` 的HTTPS模式。

Zeabur建立**新服務**連接本庫 main，使用根目錄Dockerfile；單一worker，監聽 `$PORT`，預設8080。掛載此服務自己的持久硬碟 `/data`，不要共用多頭硬碟。環境為 `SHORTETH_DATA_DIR=/data`、`SHORTETH_CLOUD=1`。首次設定碼在受保護部署日誌出現一次，於網站建立密碼後失效。API不放GitHub或Docker映像。

## 已驗證與仍需確認

網站提供「本機模擬測試」及「固定1.95%歷史回測」；命令列等效為：

```powershell
py -3.14 -m pytest -q tests
py -3.14 research/replay_frozen.py
```

保存59160根小時資料；核對113筆進出場、每筆數量及損益，並逐小時核對正式程式出場函式。基準总投入23500U、淨利146060.38U、回撤56.91%。這是Binance代理加模型成本，非Bitget真實歷史。凍結研究副本在 `research/reference`；程式核對不重新選參數。

此版本尚未在使用者Bitget帳戶送出測試單；離線通過不代表交易所實際成交已驗證。市價成交、停機、Funding及實際風險階梯可造成差異，不能保證收益或不強平。出場依賴服務運行、最新資料和交易許可，停用自動下單後也不會自動出場。
